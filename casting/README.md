# Voidlink — Casting Folder

Operational folder for the voice acting workstream. Sits at repo root next to `PRODUCTION.md`. Files here are *artefacts to share with talent and agencies*; nothing here ships in the game binary.

## Contents

- [`NDA.md`](NDA.md) — mutual non-disclosure agreement to send to every shortlisted voice actor before sharing full scripts.
- [`scripts/`](scripts/) — per-character draft recording scripts (one file each).

## Workflow

1. Cast via Voquent (see [`../PRODUCTION.md`](../PRODUCTION.md) §B for the casting briefs and field-by-field form fills).
2. Once you have a shortlist per role, send [`NDA.md`](NDA.md) to each shortlisted actor.
3. Once NDAs are returned signed, share the relevant script from `scripts/`.
4. Recording sessions: live direction via Zoom, talent records 48 kHz / 24-bit WAV dry, one round of free pickups within 7 days.
5. Final audio integrated into FL Studio for processing (MAGNUS chain, Dispatch chain) and game engine.
